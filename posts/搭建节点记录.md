# 安装面板
购买vps付款完成之后，平台会发来一封邮件，包含了vps的ip以及root身份的初始密码，我们需要用这些信息来连接vps（使用ssh工具）。ssh连接上之后，开始安装[3x-ui面板](https://github.com/MHSanaei/3x-ui)。在root身份下直接运行官方提供的一键脚本：
```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```
在脚本的执行过程中，可能会出现下面这些选项
```bash

```
```bash

```
```bash
Choose SSL certificate setup method:
1. Let's Encrypt for Domain (90-day validity, auto-renews)
2. Let's Encrypt for IP Address (6-day validity, auto-renews)
3. Custom SSL Certificate (Path to existing files)
Note: Options 1 & 2 require port 80 open. Option 3 requires manual paths.
Choose an option (default 2 for IP):    #填2，或者直接回车
```
```bash
Do you have an IPv6 address to include? (leave empty to skip):    #直接回车
```
```bash
Port to use for ACME HTTP-01 listener (default 80):    #直接回车
```
最后等待脚本执行完成，找到形如下面的信息

这里的`port`是之前脚本运行的时候输入的端口，`Access URL`是访问面板使用的链接。直接把`Access URL`的内容复制到浏览器就能访问面板了。`Username`和`Password`就是登录面板使用的账号和密码，粘贴进面板即可。至此面板安装完成

# 搭建节点
我打算搭建vless+reality协议的节点。在经过了解与学习之后，得知reality协议需要"偷"别人的域名，即去请求你设置的目标网站，获取该网站真实的 TLS 证书、密钥交换算法和握手特征。而安全性最高方案就是偷自己的域名，如果自己的域名对应的服务还运行在这台服务器上，还能让这个过程的延迟达到最低。恰好我之前使用的是[fuwari静态博客](https://github.com/saicaca/fuwari)，在构建完静态资源之后运行占用的内存很低，所以我打算直接在服务器上搭建一个web服务。（当然不想折腾也完全可以使用3x-ui默认使用的大厂域名，跳过搭建web服务这一步即可）
## 1.搭建web服务
在运行web服务这里，我选择使用caddy来运行
### 安装caddy
直接执行下面的命令来安装caddy
```bash
apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.debian.conf' | tee /etc/apt/sources.list.d/caddy-stable.list
apt update
apt install caddy -y
```
命令运行结束之后，修改caddy的配置。运行下面的命令
```bash
nano /etc/caddy/Caddyfile
```
然后修改内容为下面的内容
```bash
:8080 {
    root * /var/www/fuwari    #这里的目录填写静态资源所在的目录
    file_server
}
```
我已经上传过资源了，就直接指定目录为我的静态资源目录。然后重启caddy
```bash
systemctl restart caddy
```
重启之后执行`curl -L http://127.0.0.1:8080`，如果能看到命令返回了网页内容，说明web服务已经运行起来了。也可以在本地通过访问`http://你的服务器ip:8080`来检测web服务是否已经在运行
### 给域名申请证书
申请证书这里可以用caddy申请，也可以用3x-ui申请。因为是要给web服务申请证书，我就用caddy来申请了。
1. 进入cloudflare或者其他服务商的dns页面，给域名添加一条A记录，内容为服务器的ip。
2. 在验证过caddy能正常运行之后，输入`nano /etc/caddy/Caddyfile`
3. 按照下面模板填入配置（确保80以及443端口可以被访问）
```
kyuhou.dpdns.org {  # 你的域名
    # 你的静态文件目录
    root * /var/www/fuwari/
    
    # 启用文件服务
    file_server
    
    # 开启压缩，提升加载速度
    encode zstd gzip
    
    # 可选：配置 404 页面回落到 index.html
    try_files {path} /index.html
}
```
输入`systemctl restart caddy`重启caddy。一段时间后尝试访问`https://你的域名`，能进入并且没有提示不安全，即可
## 2.配置节点
进入面板，点击左侧入站列表，然后点击添加入站![添加节点](https://img-bucket.303302.xyz/2026/04/20260428220922832.png)协议选择vless，端口随意填写![选择协议和端口](https://img-bucket.303302.xyz/2026/04/20260429221528805.png)`安全`选择`reality`，并在`Target`填入刚刚用caddy申请证书的`域名:443`，`SNI`直接填写域名即可。如果在上一步没有搭建web服务和申请证书，也可以直接用预置的大厂域名信息。不过不管填写的是什么，都要保证这个域名在大陆是可以被正常访问的。然后点击下面公钥和私钥下的`Get New Cart`创建一对密钥![reality配置](https://img-bucket.303302.xyz/2026/04/20260429221728609.png)下方的Sniffing我也不知道有什么用，但是开不开好像使用都没有问题
最后点击创建即可。

创建完之后点击节点ID旁的加号，再点击下方弹出的菜单的编辑按钮![客户端配置](https://img-bucket.303302.xyz/2026/04/20260429223534061.png)把flow修改为`xtls-rprx-vision`并保存修改![修改flow](https://img-bucket.303302.xyz/2026/04/20260429223850753.png)
