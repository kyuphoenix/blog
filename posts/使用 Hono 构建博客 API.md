# 获取免费二级域名

[视频教程](https://www.bilibili.com/video/BV1msAUz3EXt)

[从DigitalPlat可以获取免费的dpdns.org](http://从DigitalPlat可以获取免费的dpdns.org)后缀免费域名

1. 点击sign up注册一个账号

![](https://img-bucket.303302.xyz/2026/02/20260227141806651.png)
2. 填写相关信息

![](https://img-bucket.303302.xyz/2026/02/20260227141806605.png)
这里的邮箱要填写自己可以长期接收到邮件的邮箱，不要太小众，有gmail可以用，qq邮箱，outlook之类的也可以用。其他的信息可以去[身份大全](https://shenfendaquan.com/)或者其他身份生成网站生成后填写。填写完成之后点击注册
![点击注册](https://img-bucket.303302.xyz/2026/02/20260227142648991.png)
  
出现success就是注册成功了
![注册成功](https://img-bucket.303302.xyz/2026/02/20260227142852982.png)
  
然后要去自己注册的时候填写的邮箱点击邮件内的链接验证，出现success就是验证成功了3. 回到[DigitalPlat](https://dash.domain.digitalplat.org/)登录刚刚注册的账号并进行github验证  
登录账号就不说了。  
网站要求关联github账号进行身份认证。这里选择也只能选择github认证，没有github账号的去注册一个。

![验证](https://img-bucket.303302.xyz/2026/02/20260227143705049.png)
认证完之后看这个notice，这里是说去他们github的仓库点一个star可以获得一个域名的名额，这样加起来总共是两个域名。点击中间的[Click here to visit our Github repo](https://github.com/DigitalPlatDev/FreeDomain)去github点一个star。  

![](https://img-bucket.303302.xyz/2026/02/20260227144054300.png)
4. 申请域名  
来到[仪表盘](https://dash.domain.digitalplat.org/panel/main)  
按照图中的指示注册域名

![注册域名](https://img-bucket.303302.xyz/2026/02/20260227145123552.png)

![查找域名](https://img-bucket.303302.xyz/2026/02/20260227150009927.png)
  
name server可以先随便填两个，先把域名拿到。[可以直接填ns1.provider.com和ns2.provider.com](http://可以直接填ns1.provider.com和ns2.provider.com)
![填写ns](https://img-bucket.303302.xyz/2026/02/20260227150507810.png)

![域名注册成功](https://img-bucket.303302.xyz/2026/02/20260227151051673.png)
  
同理再注册第二个域名
从[DNSHE](https://my.dnshe.com/)可以获取免费的二级域名

1. 先注册一个账号

![前往注册账号](https://img-bucket.303302.xyz/2026/02/20260227160837137.png)

![注册账号](https://img-bucket.303302.xyz/2026/02/20260227161342663.png)

![前往注册域名](https://img-bucket.303302.xyz/2026/02/20260227161620501.png)
2. 注册域名  
可以看到免费额度还是挺多的。我们前往注册域名

![注册域名](https://img-bucket.303302.xyz/2026/02/20260227162109539.png)
这里有两个后缀是需要邀请码才能注册的，可以开个小号互相注册也可以注册其他的
![选择域名后缀](https://img-bucket.303302.xyz/2026/02/20260227162600677.png)
这里看到主页出现域名就是注册成功了。
![注册成功](https://img-bucket.303302.xyz/2026/02/20260227162903243.png)

需要注意的是这两个平台都不是注册之后就永久使用的，默认持有时间为一年，要在到期前去网站手动点击续期，否则域名就会被收回

# 购买一级域名

这里我推荐去[spaceship](https://www.spaceship.com/)买一个6~9位数字+xyz域名，每年只需要5块不到  
首页可以搜索域名

![搜索域名](https://img-bucket.303302.xyz/2026/02/20260227171818747.png)

  
以这个域名为例

![购买域名](https://img-bucket.303302.xyz/2026/02/20260227172646466.png)

  
在注册账号并登录之后就可以加入购物车并购买了  
spaceship支持支付宝付款，可以直接添加支付宝为支付方式。  
添加付款方式的时候地址可以填真的也可以填假的，没什么关系。
